# Security policy

## Reporting

Do not publish confidential documents, credentials, personal data, or proprietary templates in an issue. Report security concerns privately through GitHub's security-advisory feature for this repository.

## File handling

The bundled tools process OOXML ZIP packages locally and create a separate output file. Treat all supplied DOCX and PPTX files as untrusted input, keep backups, and review repaired output before distribution.
