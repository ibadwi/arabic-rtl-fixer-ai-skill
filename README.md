# Arabic RTL Fixer AI Skill

An AI skill for fixing Arabic RTL, BiDi, and mixed Arabic-English content in documents — Word (DOCX), PowerPoint (PPTX), and other formatted files.

## Arabic RTL Fixer

Detect, repair, and validate Arabic and Arabic-English documents with correct right-to-left text direction, paragraph-level RTL, bidirectional (BiDi) punctuation and numeral handling, mixed-language runs, native bullets and lists, and Arabic language metadata — while keeping text natively editable in Word and PowerPoint.

Install globally:

```bash
npx skills add ibadwi/arabic-rtl-fixer-ai-skill -s arabic-rtl-fixer -g -y
```

Start a new task after installation, then ask the agent to fix or validate an Arabic DOCX or PPTX file.

Requirements:

- Node.js with `npx`
- Python 3

# مهارة إصلاح النصوص العربية (Arabic RTL Fixer AI Skill)

مهارة ذكاء اصطناعي لإصلاح مشاكل الاتجاه من اليمين إلى اليسار (RTL) والنص ثنائي الاتجاه (BiDi) والمحتوى المختلط عربي‑إنجليزي في المستندات — ملفات Word‏ (DOCX) وPowerPoint‏ (PPTX) والملفات المنسّقة الأخرى.

## إصلاح النصوص العربية

اكتشاف وإصلاح والتحقق من المستندات العربية والعربية‑الإنجليزية، مع ضبط اتجاه النص من اليمين إلى اليسار على مستوى الفقرة، ومعالجة علامات الترقيم والأرقام ثنائية الاتجاه، والمقاطع مختلطة اللغة، والتعداد والقوائم الأصلية، وبيانات اللغة العربية في المستند — مع الإبقاء على النص قابلاً للتحرير أصلياً داخل Word وPowerPoint.

التثبيت بشكل عام:

```bash
npx skills add ibadwi/arabic-rtl-fixer-ai-skill -s arabic-rtl-fixer -g -y
```

بعد التثبيت، ابدأ مهمة جديدة ثم اطلب من الوكيل إصلاح أو فحص ملف DOCX أو PPTX عربي.

المتطلبات:

- Node.js مع `npx`
- Python 3
